## 📖 Overview

**AI Analytics Copilot** is an AI-powered data analytics platform that enables users to analyze datasets effortlessly. Simply upload a CSV file, and the application automatically performs Exploratory Data Analysis (EDA), generates interactive visualizations, detects data quality issues, and provides AI-generated business insights.

Designed for **Data Analysts, Data Scientists, Students, and Business Professionals**, the platform reduces manual analysis time and makes data exploration accessible through an intuitive interface.

## ⚙️ Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/AI-Analytics-Copilot.git
cd AI-Analytics-Copilot
```

---

### 2️⃣ Backend Setup

Create a virtual environment

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Start the backend

```bash
uvicorn app.main:app --reload
```

Open Swagger UI

```
http://127.0.0.1:8000/docs
```

---

### 3️⃣ Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
